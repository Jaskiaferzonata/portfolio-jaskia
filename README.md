# Portofolio Jaskia Ferzonata

## Struktur
```
portofolio-jaskia/
├── index.html      -> isi konten (teks, pengalaman, proyek, kontak)
├── css/
│   └── style.css   -> tampilan (warna, font, layout)
└── img/
    └── foto.jpg    -> foto profil (ganti dengan nama file yang sama)
```

## Cara mengedit
- **Teks & konten**: buka `index.html`, ubah teks di antara tag.
- **Tambah proyek**: salin satu blok `<article class="card project">` di bagian `#proyek`.
- **Tambah pengalaman**: salin satu blok `<li>` di dalam `<ol class="tl">`.
- **Warna**: ubah variabel di awal `css/style.css` (`--blue`, `--sun`, `--paper`, `--ink`).
- **Foto**: timpa `img/foto.jpg` (rasio persegi paling bagus).
- **Menjalankan**: klik dua kali `index.html` di browser.
